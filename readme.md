# 📊 Brazil – Votuporanga Elections Data Analysis

## 📌 Project Overview
This project presents an **exploratory data analysis (EDA)** of election results from **Votuporanga, Brazil**, aiming to extract insights through data cleaning, visualization, and statistical interpretation. The analysis is implemented using **Python** in a **Jupyter Notebook**, following good practices in data science and reproducible research.

The project is suitable for:
- Data analysis and visualization portfolios
- Academic and educational purposes
- Beginners to intermediate data science projects

---

## 🎯 Objectives
- Analyze election-related datasets from Votuporanga
- Identify voting patterns and distributions
- Apply data cleaning and preprocessing techniques
- Create clear and informative visualizations
- Demonstrate a structured data analysis workflow

---

## 🛠️ Technologies & Tools
- **Python 3**
- **Jupyter Notebook**
- **Pandas** – data manipulation
- **NumPy** – numerical operations
- **Matplotlib / Seaborn** – data visualization

## 🚀 How to Run the Project
1. Clone the repository:
```bash
git clone https://github.com/your-username/your-repository-name.git
```

2. Navigate to the project folder:
```bash
cd your-repository-name
```

3. (Optional) Create and activate a virtual environment:
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\\Scripts\\activate     # Windows
```

4. Install dependencies:
```bash
pip install pandas numpy matplotlib seaborn jupyter
```

5. Open the notebook:
```bash
jupyter notebook
```
